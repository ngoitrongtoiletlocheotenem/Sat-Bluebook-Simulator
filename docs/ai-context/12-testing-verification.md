## Commands and scope

All commands run from the `Works` repository root; authoritative scripts are in [package.json](../../package.json).

| Command                        | Actual scope                                                                                                                                       |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm test`                     | `tsx --test server/**/*.test.ts`: Node test runner with TypeScript; pure engines plus SQLite/Supertest integration and nested asset/import checks. |
| `npm run test:e2e`             | Playwright Chromium UI journeys in `tests/`, one worker, no retries.                                                                               |
| `npm run typecheck`            | Strict `tsc --noEmit` over client/shared/server/tests and Vite/Playwright configuration.                                                           |
| `npm run lint`                 | ESLint over client/shared/server/tests; scripts/docs are outside this command.                                                                     |
| `npm run format:check`         | Prettier check over client/shared/server/tests, root JSON/TS, docs and README; it does not include root `AGENT_MEMORY.md`.                         |
| `npm run format`               | Rewrites the same Prettier targets; review the diff before applying to an existing worktree.                                                       |
| `npm run build`                | Typecheck, Vite production frontend, tsup server bundle.                                                                                           |
| `npm run check`                | Lint → typecheck → backend tests → build; excludes browser/live Desmos/format/audit checks.                                                        |
| `node scripts/smoke-local.mjs` | Smoke against an already running built app; does not start/stop it.                                                                                |
| `npm run test:desmos`          | Isolated built-server smoke requiring an authorized configured Desmos key and network.                                                             |
| `npm audit`                    | Dependency advisory lookup; no package script wraps it, and an old clean result is not current evidence.                                           |

The lockfile resolves Playwright 1.63.0, tsx 4.23.15, TypeScript 5.9.3, ESLint 9.39.5, and Prettier 3.9.9. Versions in `package.json` are ranges, not the exact installed lock resolutions.

## Browser coverage and isolation

[playwright.config.ts](../../playwright.config.ts) starts `npm run dev` on API port 3001 and Vite port 5173, `reuseExistingServer: false`. Stop a running local/development instance before this suite; the test launcher must own both ports. Each run uses a UUID SQLite path and upload directory beneath `.runtime`, blank `DATABASE_URL`, generated administrator password, test-mode cookies, seeded content, and blank browser Desmos key. Test credentials/attempts do not enter the normal local database.

Current source contains eleven top-level browser tests:

| File                                                     | Exact test names                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [student.spec.ts](../../tests/student.spec.ts)           | `complete adaptive SAT, persist tools, print report, inspect mistakes and retry`; `offline autosave reconnects and practice pause survives reload`; `administrator bank versions, manual/random blueprints, import formats and server permissions`; `annotations cross formatting and original chart supports zoom, pan and numeric tutor feedback`; `only one browser tab writes an attempt until explicit takeover`; `student authors, previews, versions and imports private questions through the UI`. |
| [image-import.spec.ts](../../tests/image-import.spec.ts) | `repair an invalid image for one parsed row and import the rendered question`; `text-only questions import without an image preparation step`; `manual image changes survive upload failure and cancel leaves the parsed row unchanged`; `a failed fourth image is detected and can be removed before confirmation`; `unavailable images in skipped duplicate and invalid rows do not block valid questions`.                                                                                              |

For targeted work, pass the checked-in file or `--grep` to `npm run test:e2e -- ...`. Reports use console list, `playwright-report/` HTML, and `test-results/e2e-results.xml`; traces/screenshots are retained on failure. Tests may generate screenshots/PDFs for review, but generating them is not an accessibility certification or pixel-baseline comparison. Browser coverage includes same-browser takeover; independent-device simultaneous writers remain a limitation.

## Local and external smoke checks

[smoke-local.mjs](../../scripts/smoke-local.mjs) loads runtime environment configuration and targets `APP_ORIGIN` or the default built local origin. It verifies health, built HTML/script, public taxonomy/session endpoint, and guest denial for questions. If administrator environment variables exist, it logs in, verifies a seeded bank of at least 352 questions, a full blueprint, readable history, and logout. `SMOKE_EXPECT_EMPTY_HISTORY=true` adds an empty-history assertion for a fresh deployment only. Without administrator configuration the protected checks are skipped. It writes `data/deployment-smoke.json`; this is not a new database or a full assessment test.

[smoke-desmos.mjs](../../scripts/smoke-desmos.mjs) requires a build and Chromium installation, owns port 3002, and starts its own server with a UUID SQLite database. It checks main-versus-calculator CSP isolation, sandboxing, a real external API response/editor/canvas, expression rendering, resize and reopen, induced network failure, the local fallback calculation, and retry recovery. It redacts key-bearing URLs/messages. It writes `.runtime/desmos-smoke.json` and generated screenshots. Its `researchedDate` field is hard-coded to 9 October 2026; that field alone does not establish a future run's date. Never copy the configured key or private source snippet into documentation.
